{# ===== 異常検知デモ(ボタンを押したときだけ発生 / 自動生成はしません) ===== #}

異常検知デモ

{% csrf_token %}

押すと ランダムな異常検知を1件作成します (種類: 転倒 / あやしい動き / 立ち入り禁止ゾーン、信頼度 70〜99%)。
実AIの検知と同じ経路を通るので、約5秒以内の通知(トースト・通知音・OS通知)、 異常検知一覧・詳細、「対応する → 解決・報告を入力」の流れまで確認できます。
自動では一切動きません(このボタンを押したときだけ)。録画は作られないため サムネイルは代替画像になります。
注意: デモのアラートで「誤検知として報告」を押すと AI設定の感度が自動調整されます。練習で連打しないようご注意ください。

{# ===== データ削除（管理） ===== #}

データ削除（管理）

{% csrf_token %}

全ての異常検知記録・自動録画・解決報告を削除し、さらに media フォルダ内のファイル(mp4・jpg をすべて)を削除します。
検知データと対応していない残骸も対象です。フォルダ自体 (alert_thumbs / camera_snapshots / recordings)は残ります。
